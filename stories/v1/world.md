# v1 見立て

このバージョンの世界を支える規則と、物語の骨子。場面を書くとき、イラストを描くとき、あとで生成の仕組みに渡す設定の元にする。

## 舞台

名前のない小さな町の、夜明け前のひととき（午前四時ごろ）。
暗がりの中には、輪郭の定まらないものがあちこちにある。三人の主人公は同じ町の同じ夜にいて、互いを知らないまま、互いを見ている。

## 規則

1. **見立ては引き寄せる。** 夜明け前、はっきり見えないものを「それだ」と見立てると、世界はそれに見合うものを本当に引き寄せる。無から生み出すのではなく、どこかに実在するものが呼び寄せられる。
2. **見た目は意識に、正体は本心に従う。** 引き寄せられたものは、見立てたとおりの姿に見える。しかしその正体は、見た者が心の底で本当に信じていることに従う。本心から信じて見立てたときだけ、本物が来る。意識と本心がずれていれば、そう見えるだけの別のものが来る。
3. **近づくほど、正体が滲み出る。** 夜明けを待たなくても、近づいて触れたり言葉を交わしたりすれば、夜のうちから見た目と正体のずれが細部から現れる。遠くから見ているだけなら、見立ては夜明けまで解けず、夜明けに正体がはっきりする。
4. **引き寄せられた者にも、それぞれの事情と意思がある。** 呼ばれた者は、自分の夜を生きている別の誰かであり、見立てによって別人に書き換わることはない。
5. **結末を決めるのは、ずれにどう向き合うかである。** 世界は裁かない。
6. **引き寄せられやすいのは、輪郭の定まらないものである。** 眠りと目覚めのあわいにいる人、行き場を失ったもの、霧や影のように形を持たないもの。見る側の想いが強いほど、見立ては遠くまで届く。三人の主人公がいずれも眠りと目覚めのあわいにいることが、互いの見立てに巻き込まれ合う理由になっている。

見立ての 3 択は、大人の二人では「願い」「怖れや現実」「切り捨て（ただの〜だ）」の型にそろえる。子どもには「ただの〜だ」がない。

## 書くときの約束

- 規則も、意識と本心のずれも、作中で説明しない。利き手、呼び名、服、影の向きといった細部の違和感で、読み手が気づけるようにする。気づかなくても物語として成り立つようにする。
- 恐怖体験に寄せない。目指すのは、夢と現実が交差する超現実の手触り。
- 結末の種類（良・中間・悪）は画面に出さない。作り手として方向は決めるが、どう受け取るかは読み手に委ねる。
- 物語は枝分かれだけの木の形にし、合流もループもさせない。同じイラストや本文を複数の場面で使わない。
- 本文は 1 場面あたり約 250〜300 字。画面に収まらなければ元の長さ（約 180 字）に戻し、それでも収まらなければ、場面の中で続きをクリックで出す。

## 物語の型（三人共通）

```
開始 ──見立て 3 択──▶ 引き寄せられた出来事（3 通り） ──行動 2 択──▶ 夜明けの結末（6 通り）
```

一人 10 場面。結末は良 2・中間 2・悪 2。

## 主人公

| ID | 名前 | 人物 | 意識の願い | 心の底の本心 |
|---|---|---|---|---|
| `windowsill` | 窓辺の人 | 十年前、大学入学と同時に家を出て、そのまま戻らない妹（澪）を待つ姉 | 妹に帰ってきてほしい | 妹はもう、ここへは帰らない。けれど、どこかで生きていてほしい |
| `sleepless` | 眠れない人 | 何日も眠れず、懐中電灯を手に夜の町を歩く青年 | 安心して眠りたい | 自分は責められて当然だと思っている |
| `child` | 子ども | 眠ったまま歩き出してしまう（夢遊病の）七歳の子。白っぽい寝間着に裸足のまま、夜中の路地を歩いている | 冒険したい、友だちがほしい | 願いとほとんどずれていない（少しだけ寂しい）。だから本物を呼び寄せる |

## 骨子

### 窓辺の人

冒頭：夜明け前に目が覚め、いつものように妹の部屋だった二階の窓辺に佇んで、月明かりの路地を見下ろす。寝起きのかすんだ目に、月明かりの路地の先の白っぽいものがぼんやりと見える。

白いものは、まだ何ものでもない。どう見立てるかによって、そこへ引き寄せられるものが変わる。「澪」と見立てれば、夢の中で呼ばれた近所の子どもが、「犬」と見立てれば行き場のない迷い犬が、「霧」と見立てれば本物の霧が引き寄せられる（規則 1・6）。

| 見立て | 引き寄せられた出来事 | 行動 → 結末 |
|---|---|---|
| 妹だ。帰ってきたんだ | 白いブラウスに白いズボン、短い髪の、家を出た十八のときの澪に見える姿が、月明かりの下から見上げて手を振る。姉にそう見えているだけなので輪郭はぼんやりしている。近づくと、七つほどの子どもだった（見た目は姉の意識、正体は本心に従う。澪は姉を「おねえ」と呼んでいた） | 迎えに降りる → **良**：近づいて言葉を交わすうち、妹ではない近所の子どもだと気づく。夢の中で呼ばれた気がして、目が覚めたら外にいたという。家まで付き添い、寂しさを抱えつつも前に進もうと思える<br>窓を開いてから名前を呼ぶ → **悪**：澪は答えず、無表情に首をかしげて棒立ちのまま見上げ続ける。疑いながら呼ぶたびに、眠っていた近所の人々が引き寄せられ、寝間着姿のまま、澪の顔をして路地に立つ（規則 2・6）。日が昇ると顔は本人のものに戻り、人々は我に返って帰っていく（規則 3・4）。姉は澪の顔を他人に重ね続けた末に、澪の本当の顔を思い出せなくなっている |
| 迷い込んだ白い犬だ | 白い犬が古い封筒をくわえ、窓の下に座って見上げる | 封筒を受け取る → **良**：遠くで元気にしているという澪の便り。姉の知らないこと（海が見える）が書かれている一方、消印だけが読めない。再会に希望を抱く<br>見なかったことにして、カーテンを引き、隣の自分の部屋に戻る → **中間**：夜明けに自分の部屋の窓から見ると、犬はもういない。封筒は届かないまま |
| ただの霧だ | 霧が路地に広がり、窓まで這い上がってくる（正体は「待つことに疲れた」本心） | 窓を閉める → **中間**：部屋は守られるが、窓の外は白いまま。待つ日々が続く<br>霧を招き入れる → **悪**：思い出の品から輪郭が抜け、空き部屋だけが残る。なぜ窓辺にいたのかも思い出せない |

### 眠れない人

冒頭：灯りの消えた家の二階の窓に、じっと動かない人影（正体は窓辺の人）。

| 見立て | 引き寄せられた出来事 | 行動 → 結末 |
|---|---|---|
| 見張られている | 町じゅうの窓に無数の人影が現れ、一斉にこちらを向く | 気のせいだと思い直す → **中間**：人影は消える。くたくたになるまで歩き、家に帰って寝ようと思い至る<br>懐中電灯で照らし返す → **悪**：無表情の無数の顔。逃げるほど追ってくる。夜が明けても、誰もが自分を監視する世界で怯えて暮らす |
| 誰かを待っている人だ | 人影が窓を開け「おかえり」と呼びかける（姉もまた彼を誰かに見立てている） | 家に入る → **良**：懐かしい布団で、何日ぶりかに深く眠る<br>人違いだと告げる → **中間**：「気をつけて帰ってね」「待っている人、帰ってくるといいですね」。灯りが朝に溶けるまで石段から眺める |
| ただの影だ | 人影が持ち主のない影になって剥がれ落ち、足元にすり寄ってくる（正体は自分を責める本心） | 影を連れて歩く → **良**：夜明けに自分の影と重なり、体が軽くなる<br>踏みつけて追い払う → **悪**：影に飲み込まれ、外は夜明けでも自分は影の世界から出られない |

### 子ども

冒頭：月明かりの路地の向こうから、小さな光が近づいてくる（正体は眠れない人の懐中電灯）。どこかの窓から見下ろされていて、自分が別の子になっていくような、くすぐったい感じがする（窓辺の人の視線）。

| 見立て | 引き寄せられた出来事 | 行動 → 結末 |
|---|---|---|
| 蛍だ | 本物の大きな蛍が、路地の奥へ誘う | ついていく → **良**：丘で無数の蛍と夜明けを見る。窓から手を振る人がいて、帰り道がわかる<br>シーツで包んで捕まえる → **悪**：シーツが脱げなくなり、誰にも姿が見えない本物のおばけになる（**要再検討**：シーツの設定をなくしたため） |
| 流れ星が落ちてきた | 本物の小さな星が、ひとつだけ願いを叶えるとささやく | 「ともだちがほしい」と願う → **良**：星が光る子どもになり、夜明けまで遊ぶ<br>空に返す → **中間**：何も起きないまま朝が来る。空に星がひとつ増えている |
| 大きな生き物の目だ | 路地全体が、眠っていた大きな生き物になって目を開ける | おばけのふりで動かない → **中間**：仲間だと思われ、朝まで動けないが無事に帰れる（**要再検討**：おばけごっこの設定をなくしたため）<br>大声で叫ぶ → **悪**：路地が組み変わり、見知らぬ町で夜明けを迎える |

## 三人の交差

| 場面 | 見る側 | 見られる側（正体） |
|---|---|---|
| 窓辺の人の冒頭 | 姉が月明かりの路地の白いものを見る | まだ何ものでもない。「澪」と見立てたときは、夢の中で呼ばれた近所の子ども |
| 眠れない人の冒頭 | 青年が窓辺の人影を見る | 妹を待つ姉 |
| 子どもの冒頭 | 子どもが近づく光を見る | 青年の懐中電灯 |
| 眠れない人「おかえり」 | 姉が暗がりの青年を誰かに見立てている | 青年 |
| 子ども「蛍」の良い結末 | 窓から手を振る人 | 姉 |
| 窓辺の人「妹」の良い結末 | 姉が、外に出ていた子どもを家まで送っていく | 子ども |

1 回の遊びは「ありえた一夜」の一つであり、三人の物語が毎回一つの夜として完全に辻褄が合う必要はない。

## イラスト

- 開始と出来事の場面は、月明かりを必ず入れて、午前四時の夜として描く。窓辺の人の路地に街灯は置かない（白いものや澪が目立ちすぎるため）。
- 結末はすべて夜明けの時間帯に描く。良い結末は、希望の持てる明るい兆しのある絵にする。悪い結末は、恐怖を感じさせる絵に寄せる。中間はその間の静かな朝にする。結末の種類を文字では示さない。
- 違和感のない、自然でリアル寄りの描写にする。形は角張らせない。
- 窓辺の人の夜の場面は、寝起きのかすんだ目で見た視界なので、全体を自然にぼかす。ぼかすのは、世界観としてぼかしたい箇所に限る。
- 比率は 3:2（1200×800）。一場面に一枚、使い回さない。
